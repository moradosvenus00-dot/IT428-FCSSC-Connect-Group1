# IT428-FCSSC-Connect-Group1

FCSSC Connect is a web-based student organization management system for IT 428, Group 1. The Module 1 React front-end prototype is in `frontend/`. See the [front-end README](frontend/README.md) for setup, routes, feature ownership, and contribution guidance.

## Team Contributions

Five members have assigned foundation and feature areas. The [Team Contributions records](docs/team-contributions/README.md) track individual responsibilities, code evidence, tests, and progress. Git commits and pull requests provide the evidence for individual GitHub contributions; member documents should be updated as work is completed.
